Fitur Unggulan

Semua yang Anda butuhkan untuk editing audio dalam satu aplikasi

✂️

Trim Presisi

Potong audio dengan akurasi milidetik menggunakan visualisasi waveform interaktif. Support multi-region trim untuk editing kompleks.

🎚️

Efek Audio

Fade in/out, gain adjustment, speed/pitch control, dan equalizer multi-band untuk hasil audio profesional.

🔄

Konversi Format

Export ke berbagai format: MP3, WAV, M4A, AAC, FLAC, OGG, dan lainnya dengan kualitas terbaik.

🔒

100% Offline

Semua processing dilakukan lokal di perangkat Anda. Tidak ada upload ke server, privasi terjamin 100%.

💻

Cross-Platform

Tersedia untuk Windows, macOS, dan Linux. Interface konsisten di semua platform.

⚡

Performa Tinggi

Dibangun dengan Rust dan FFmpeg native untuk processing audio secepat kilat, bahkan untuk file besar.

Dibangun dengan Teknologi Modern

Stack teknologi terbaik untuk performa dan pengalaman pengguna optimal

Frontend

  • React 18 + TypeScript
  • Vite (Build Tool)
  • Zustand (State Management)
  • WaveSurfer.js
  • Tailwind CSS

Backend

  • Rust (Core Processing)
  • Tauri v2 (Desktop Framework)
  • FFmpeg (Audio Engine)
  • FFprobe (Metadata)
  • Tokio (Async Runtime)

DevOps

  • GitHub Actions (CI/CD)
  • Cargo (Package Manager)
  • npm (Frontend Packages)
  • Docker (Testing)
  • Sentry (Error Tracking)

Testing

  • Jest + React Testing Library
  • Cargo Test (Rust)
  • Playwright (E2E)
  • TypeScript Strict Mode
  • ESLint + Prettier
