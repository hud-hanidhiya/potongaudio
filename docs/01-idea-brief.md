# Idea / Problem Brief — Potong Audio

## Ini apa?
Aplikasi desktop offline cross-platform untuk memotong (trim), memberi efek
dasar (fade, gain, speed), dan mengonversi format file audio.

## Kenapa dibangun
Kebutuhan praktis: alat potong audio sederhana yang benar-benar offline,
ringan, tidak terikat langganan/iklan. Juga kesempatan eksplorasi
arsitektur hybrid Tauri (Rust) + React.

## Untuk siapa
Awalnya untuk pemakaian sendiri. Repo publik di GitHub + landing page,
jadi berpotensi dipakai orang lain, tapi bukan target utama v1.

## "Berhasil" itu seperti apa
v1 shipped: install di Windows & Linux, upload audio, trim satu region,
atur fade/gain/speed, export ke format umum — semua offline, tanpa crash,
ukuran installer wajar.

## Trigger / urgensi
Tidak ada tenggat eksternal — project personal, jalan sesuai waktu luang.
